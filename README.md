# Nett — privacy and support site

Public static pages for the Nett iOS app.

- [Privacy Policy](privacy.html)
- [Support](support.html)
- [Home](index.html)

This repository publishes informational pages only, and does not store user financial data.

## GitHub Pages

Configure **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

Expected site:
- https://szha270-git.github.io/nett-privacy/
- https://szha270-git.github.io/nett-privacy/privacy.html
- https://szha270-git.github.io/nett-privacy/support.html

## Release checks

Before public App Store submission, verify the privacy statements against the final production binary, included SDKs, analytics, Apple's privacy nutrition-label requirements and actual app behaviour. Publish a private developer support contact method and update the public support/privacy pages if appropriate. GitHub issues are public and are **not suitable for sensitive financial or personal information**.
